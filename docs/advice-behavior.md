# AI学習アドバイスは習得状況でどう変わるか（実測の記録）

> **追記（2026-08-12）**: 以下は修正前の記録である。
> 現在は、APIキーが無くても習得状況から文面を組み立てるようにした（`server/advice.ts`）。
> 変わらなかった点・変えた点は末尾の「7. その後の修正」に書いてある。

ダッシュボードの「AI学習アドバイス」（`POST /api/gemini/advice`）が、
学習者の単語習得状況に応じて実際にどう文面を変えるかを測った記録。

- 測定日: 2026-08-11
- 対象: `server.ts` の `/api/gemini/advice`、`src/components/Dashboard.tsx` の `handleFetchAdvice`
- 方法: supertest で実際にエンドポイントを叩き、返ってきた文字列をそのまま比較した

---

## 1. アドバイスに渡している情報

`Dashboard.tsx` が送るのは次の16個の数値だけ。学習者の解答履歴そのものや、
どの単語を間違えたかは送っていない。

| 送る項目 | 中身 | 出どころ |
|---|---|---|
| `juniorStats` / `seniorStats` / `senior2Stats` / `senior3Stats` / `advancedStats` | 各レベルの `{ correct, total, rate }` | `getLevelCounts(level)` |
| `wrongWordsCount` | 苦手単語の語数 | `wrongWords.length` |

`correct` は「習得済み」の語数で、判定は間隔反復のボックス2以上
（`isMastered`）。1回まぐれで正解しただけでは増えない。
`rate` は `correct / total` を四捨五入した百分率。

サーバー側は受け取った値を `toSafeCount` で
「0以上・1,000,000以下の整数」に正規化する（文字列や負数はプロンプトに入れない）。

## 2. APIキーが無いとき ← **ほとんど変わらない**

7通りの習得状況で実測した結果、**変化したのは苦手単語の個数を表示する1行だけ**だった。

| プロファイル | 習得状況 | 苦手 | 返ってきた文面 |
|---|---|---|---|
| A | 全レベル 0% | 0語 | 基準 |
| B | 初級 100%・以降 0% | 12語 | A と**1行だけ**違う（個数） |
| C | 高2まで7割・上級 0% | 40語 | A と**1行だけ**違う（個数） |
| D | 全レベル9割超 | 0語 | **A と完全に同一** |
| E | 全レベル 0% | 300語 | A と**1行だけ**違う（個数） |
| F | 初級 0%・上級 80% | 5語 | A と**1行だけ**違う（個数） |
| G | 異常値（負数・文字列） | 1,000万 | A と**1行だけ**違う（個数） |

実際の文面（プロファイル A）:

```
### 🎉 AI学習アドバイスへようこそ！

現在、**中学生レベル**は習得度高めですが、**高校レベル以上**の難単語に挑戦すると
語彙力アップの伸びしろが大きく広がります。

**💡 今後のおすすめ勉強法:**
- 新規の単語クイズを毎日10〜20問続け、知っている単語を増やしましょう。
- 「間違えた単語の復習」タブに現在 **0 個** 溜まっています。
  ここを空っぽにすることを最初の目標にして繰り返してください。
- 覚えた単語が200語を超えると、**「AI英語日記モード」**が自動開放されます！
  学んだ単語を日常エッセイで使い切る快感をぜひ体験してください。
```

差し替わるのは `**0 個**` の数字だけ。`wrongWordsCount` 以外の15個の数値は
**受け取ってはいるが、文面には一切反映されない**。

### ここから分かること

1. **プロファイル D（全レベル9割超・苦手0語）と A（完全な初学者）の文面が1バイトも違わない。**
   習得を終えた学習者にも「高校レベル以上に挑戦すると伸びしろが広がります」と表示される。

2. **「中学生レベルは習得度高め」は、事実と無関係に必ず表示される。**
   初級を1語も習得していないプロファイル A・E・F にも同じ文が出る。
   実測に基づかない断定を、学習者は「AIが自分の状況を見て言っている」と読む。

3. 苦手単語が300語あっても0語でも、勧める行動は同じ
   （「毎日10〜20問」「復習タブを空にする」「200語で日記モード解放」）。

## 3. APIキーがあるとき ← 変わるのはプロンプトだけ

キーがある場合は Gemini が文面を生成する。**この環境にはキーが無いため実行できていない。**
記録できるのは「モデルに何を渡しているか」までで、返ってくる文面は生成のたびに変わる。

モデルに渡すプロンプトのうち、習得状況で変わる部分は以下の6行:

```
- 中学生レベル: 正解数 {correct}/{total} ({rate}%)
- 高校1年生レベル: 正解数 {correct}/{total} ({rate}%)
- 高校2年生レベル: 正解数 {correct}/{total} ({rate}%)
- 高校3年生レベル: 正解数 {correct}/{total} ({rate}%)
- 大学生・社会人レベル: 正解数 {correct}/{total} ({rate}%)
- 現在登録されている、間違えた単語(復習が必要な単語)の数: {wrongWordsCount}個
```

残りの指示（挨拶を入れる／得意なレベルと改善テクニックに触れる／応援する／
先生風のトーン／150〜200文字／Markdown）は固定。

つまり **キーがあるときは16個の数値すべてが文面に効きうる**。
キーが無いときとの差はここにある。

### 生成に失敗したときの経路

APIキーはあるが呼び出しが失敗した場合（クォータ超過など）は、
キーが無いときとほぼ同じ固定文が返る（末尾に「(ローカルAI)」と注記が付く）。

この経路の文面には誤植がある。

```
- 新規 of 単語クイズを毎日10〜20問続け、…
       ^^^ 不要な "of"
```

## 4. 参考: 弱点分析はキーが無くても習得状況で変わる

同じ「AI」タブの「弱点分野の自動分析」（`/api/gemini/weakness-analysis`）は、
キーが無くても `buildFallbackWeaknessAnalysis` が**実際に間違えた単語から**
品詞の分布を数えて文面を作る。

```
間違えた単語の中では「動詞」が最も多く(45%)、ここが伸びしろのポイントです。
```

こちらは送られた単語が変われば要約も割合も変わる。
アドバイスのほうも同じ作りにできるはずだが、現状はそうなっていない。

## 5. 再現方法

```ts
// npx tsx で実行。GEMINI_API_KEY を空にしてフォールバック経路を測る
process.env.GEMINI_API_KEY = "";
const { app } = await import("./server");
const res = await request(app).post("/api/gemini/advice").send({
  juniorStats: { correct: 1050, total: 1062, rate: 99 },
  // …残り4レベル…
  wrongWordsCount: 0
});
console.log(res.body.advice);
```

習得状況を変えて2回叩き、返り値を比較すれば、
差が `**N 個**` の1行だけであることを確認できる。

## 7. その後の修正（2026-08-12）

この記録を受けて `server/advice.ts` を作り、次のように変えた。

### 変えなかったこと

**「押すたびに毎回APIを呼ぶ」はもともとそうなっていた。** クライアントにキャッシュは無く、
`handleFetchAdvice` はボタンを押すたびに必ず `/api/gemini/advice` へ行く。
「最新の回答進捗で再分析」も同じ経路である。呼ばれていなかったのはサーバーから
Gemini への部分で、原因は APIキーが設定されていないことだった。

### 変えたこと

| | 修正前 | 修正後 |
|---|---|---|
| キーが無いとき | 固定文（苦手語数だけ差し替え） | 習得状況から組み立てる |
| キーがあるとき | 数値16個をプロンプトに列挙 | 数値＋読み取った分析を渡す |
| 生成に失敗したとき | 誤植入りの固定文 | 手元の分析に切り替える |
| 出どころの表示 | 無し | AI生成かアプリ生成かを画面に出す |

読み取る内容は次のとおり。いずれも受け取った数値だけで言えることに限っている。

- 学習の段階（未開始 / 序盤 / 進行中 / 仕上げ）
- 習得語数と全体に対する割合
- **いま取り組むべきレベル** — 学習順に見て最初に80%未満のレベル。
  上級だけ進んでいても、下が空いていればそちらを先に挙げる
- まだ1語も習得していないレベル
- 苦手単語の量に応じた扱い方（0 / 20以下 / 100以下 / それ以上で分岐）

同じ7プロファイルで測り直すと、A〜Gすべてが別々の文面になった。
とくに D（全レベル9割超）は「仕上げの段階」と判定され、
長文読解と文法ガイドへ移るよう勧める内容に変わっている。

不変条件は `tests/advice.test.ts`（32件）と `tests/serverRoutes.test.ts` の
「学習アドバイス」（7件）で固定した。
「習得状況が違えば文面も違う」「初学者に習得度が高いと言わない」も含まれる。
